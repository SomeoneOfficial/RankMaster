PWA notes for this repo

Add these tags in <head> of index.html:

<link rel="manifest" href="./public/manifest.webmanifest">
<link rel="icon" type="image/png" sizes="192x192" href="./public/icons/icon-192x192.png">
<meta name="mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="default">
<meta name="theme-color" content="#000000">

Service worker registration lives in:

assets/js/service-worker-register.js

Current registration call:

if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('./sw.js')
    .then(reg => console.log('Service Worker registered!', reg))
    .catch(err => console.error('Service Worker error:', err));
}
